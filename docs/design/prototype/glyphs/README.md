# Controller button glyphs

Button prompts for the TV mode card, from **Input Prompts 1.5A by Kenney**
(<https://kenney.nl/assets/input-prompts>), licensed CC0 1.0 (see `License.txt`).
Only the glyphs the card uses are copied here; `map.json` says which glyph each
prompt set uses for each button. No brand logo is included (the pack's Xbox guide
glyph is the Xbox logo and is left out); the Home / Guide button has no glyph.

- `xbox` — Xbox Series. `ps` — PlayStation (DualSense; L1/R1/L2/R2, Create, Options).
- `nintendo` — Switch 2 (L/R, ZL/ZR, −/+).
- `8bitdo` — 8BitDo Pro series: the plain letter glyphs, L/R, rounded L2/R2, −/+.

The card draws each glyph as a CSS mask filled with the theme's text colour, so
the white artwork works in light and dark.
